   "Quick setup — if you've done this kind of thing before"
   
   COPIA EL ENLACE HTTPS (será parecido a esto):
   https://github.com/Solinntech/solinntech-website.git


PASO 2: VINCULAR REPOSITORIO LOCAL CON GITHUB
──────────────────────────────────────────────

1. Abre PowerShell
2. Navega al proyecto:
   cd "C:\Users\Andres M\Documents\solinntech-website"

3. Ejecuta ESTE comando (reemplaza la URL que copiaste):
   git remote add origin https://github.com/Solinntech/solinntech-website.git

4. Luego:
   git push -u origin main

5. AQUÍ TE PEDIRÁ AUTENTICACIÓN. OPCIONES:

   🔐 OPCIÓN A: Usar Personal Access Token (RECOMENDADO)
   ─────────────────────────────────────────────────

   b) Haz clic en "Generate new token" 
   c) Dale este nombre: "GitHub Pages"
   d) Marca estos permisos:
      ☑ repo (Full control of private repositories)
   e) Haz clic en "Generate token"
   f) COPIA el token (aparece una sola vez, no se ve de nuevo)
   g) Vuelve a PowerShell, cuando pida "password"
   h) Pega el token completo

   🔐 OPCIÓN B: Usar GitHub CLI
   ────────────────────────────
   a) git push -u origin main (sin remote aún)
   b) Se abrirá navegador GitHub para autenticación
   c) Autoriza
   d) Listo

6. Verás mensajes como:

PASO 3: ACTIVAR GITHUB PAGES
────────────────────────────

1. Ve a tu repositorio: https://github.com/Solinntech/solinntech-website

2. Haz clic en "Settings" (engranaje arriba a la derecha)

3. En el menú izquierdo, busca "Pages" (está abajo de "Security")

4. En la sección "Build and deployment":
   ┌──────────────────────────────────────────┐
   │ Source: Deploy from a branch            │
   │ Branch: main  /  (root)                  │
   │                                          │
   │ [Save]                                   │
   └──────────────────────────────────────────┘

5. Haz clic en [Save]

IMPORTANTE: Este paso requiere que hayas registrado el dominio

A) EN GITHUB (Settings → Pages):
   ┌──────────────────────────────────────┐
   │ Custom domain: solinntech.com       │
   │ [Save]                               │
   └──────────────────────────────────────┘

   GitHub creará un archivo CNAME automáticamente

B) EN TU REGISTRADOR DE DOMINIO (Namecheap, GoDaddy, etc):
   
   1. Inicia sesión en el registrador donde compraste solinntech.com
   
   2. Busca "Manage DNS" o "DNS Settings"
   
   3. Encontrarás una tabla de DNS Records, MODIFICA así:
   
      ┌─────────┬────┬──────────────────────┐
      │ Type    │ A  │ Points to            │
      ├─────────┼────┼──────────────────────┤
      │ A       │ @  │ 185.199.108.153      │
      │ A       │ @  │ 185.199.109.153      │
      │ A       │ @  │ 185.199.110.153      │
      │ A       │ @  │ 185.199.111.153      │
      └─────────┴────┴──────────────────────┘
   
   4. Si tienes un registro CNAME para www:
      www CNAME solinntech.github.io
   
   5. Haz clic en "Save"
   
   6. ESPERA 24-48 HORAS (a veces funciona en 10 minutos)
